# Licensr

Licensr is a Zed editor extension that inserts common software licenses using snippets to have a smoother coding experience.

# Usage 

To use Licensr, simply type `license-` followed by the license name in a comment line and press `enter` to insert the license text, for a list of all available licenses, go to the [licensr snippets](https://github.com/DankDown10256/licensr/tree/master/snippets/snippets.json) page. For "LICENSE" files in the language buffer down click on it and select Plain Text, if you don't do this Zed will not recognize the file as a text file and will not apply the license snippets.
